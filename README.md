# Run Errands Kenya - CBD Foot Messenger & Logistics Engine

A lightweight, mobile-first web app tailored for on-foot couriers, errand runners, and building-to-stage parcel deliveries in Nairobi CBD.

## Key Features
- **Messenger Onboarding & Verification:** Quick signup requiring National ID number and verified phone number with a KES 100 refundable commitment float.
- **Flexible Destinations:** Open destination handling for CBD building drop-offs, bus/matatu stage deliveries (e.g., Easy Coach, Tea Room), or vehicle/boda transfers for outbound parcels.
- **Stairs & Floor Surcharge Engine:** Automatically factors in stair steps and non-functional building lifts into courier payout calculations.
- **Micro-Zone Walking Distance:** Pricing optimized for block-to-block and cross-CBD walking distances.
- **Automated Revenue Split:** Real-time calculation of 85% messenger earnings and 15% platform commission deducted automatically from the active float.
- **1-Click WhatsApp Dispatching:** Instantly sends dispatch updates and tracking notifications directly to customers via WhatsApp.

## How to Publish to GitHub Pages
1. Replace `README.md` and `index.html` in your GitHub repository (`Run-Errands-Kenya`).
2. Go to **Settings** -> **Pages**.
3. Under **Branch**, select `main` (or `master`) and click **Save**.
4. Access your live Web App at `https://<your-username>.github.io/<repository-name>/`.
