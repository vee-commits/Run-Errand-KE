# Run Errands Kenya - Multi-Zone Sourcing & Foot Logistics Engine

A lightweight, mobile-first web app designed for on-foot couriers, errand runners, and physical item sourcers across Nairobi (Gikomba, Eastleigh, Luthuli/Kamukunji, CBD, Westlands, and surrounding areas).

---

## Features

- **Dual-Role Interface:** Seamlessly switch between **Customer View** (posting errands, setting physical search parameters) and **Runner View** (verifying identity, accepting nearby jobs).
- **Physical Market Sourcing Engine:** Dynamic surcharge calculations (+KES 150 to KES 300) for runners who physically hop stalls, compare prices, check quality, and send photo proof in places like Gikomba or Eastleigh.
- **Citywide Coverage & Multi-Mode Transit:** Supports pricing for foot walk, public matatu transit (+fare inclusion), and express boda handovers across all major Nairobi zones.
- **Trust-Based Onboarding & Float Management:** Free runner onboarding requiring only National ID and M-Pesa phone number verification, with an integrated 85% runner / 15% platform fee balance engine.
- **1-Click WhatsApp Dispatches:** Pre-formats errand details into ready-to-send WhatsApp messages for instant communication.
